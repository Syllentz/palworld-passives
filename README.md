# Palworld 1.0 — Pal Passive Skills

- **[Passive table](https://syllentz.github.io/palworld-passives/)** — searchable, sortable, filterable table of all 114 Pal passive skills in Palworld 1.0, with the in-game tier icons.
- **[Build calculator](https://syllentz.github.io/palworld-passives/calculator.html)** — pick up to 4 passives and see the combined stat changes. Builds can be shared by link.

Data and icons from [paldb.cc](https://paldb.cc/en/Passive_Skills) (extracted from the game files). Palworld and its assets © Pocketpair, Inc. Fan-made, non-commercial.
