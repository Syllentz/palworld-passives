# Palworld 1.0 — Passives & Breeding

- **[Passive table](https://syllentz.github.io/palworld-passives/)** — searchable, sortable, filterable table of all 114 Pal passive skills in Palworld 1.0, with the in-game tier icons.
- **[Passive build calculator](https://syllentz.github.io/palworld-passives/calculator.html)** — pick up to 4 passives and see the combined stat changes. Builds can be shared by link.
- **[Breeding planner](https://syllentz.github.io/palworld-passives/breeding.html)** — pick the Pal you want and get the 10 easiest routes, each drawn as a breeding tree with a step-by-step list (catch these, breed A + B → C). Routes respect your max catch level and the Pals you own, and can include mutation steps with their odds. Also shows every child a Pal can make, including mutation outcomes.

Normal breeding data: [PalCalc](https://github.com/tylercamp/palcalc) (MIT), datamined from the Palworld 1.0 game files.
Mutation model, passive data and icons: [paldb.cc](https://paldb.cc/). Palworld and its assets © Pocketpair, Inc. Fan-made, non-commercial.
